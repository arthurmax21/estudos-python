# Controle de Estoque e Expedição Diária

Projeto prático desenvolvido em **Python** para simular a conferência diária de estoque em uma operação logística, calculando saldos, emitindo alertas de reposição e gerando um relatório automático.

# Funcionalidades
* Cadastro dinâmico de múltiplos produtos na mesma execução.
* Cálculo automático do saldo final de caixas após as saídas do dia.
* Alerta visual para itens com estoque crítico (menor ou igual a 15 caixas).
* Soma do volume total de caixas expedidas no turno.
* Exportação automática do resumo final para um arquivo `relatorio_expedicao.txt`.

# Tecnologias Utilizadas
* **Python 3.14**
* **Git & GitHub** para versionamento de código

# Como executar o projeto
1. Certifique-se de ter o **Python 3** instalado na máquina.
2. Baixe o arquivo `resumo_dia.py`.
3. Execute no terminal com o comando:
   ```bash
   python estoque.py
   ```
